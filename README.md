# 名稱資料清理與權威名稱比對工具

這是一個以 Python 與 Streamlit 製作的資料清理工具，主要處理資料表中的機構／企業名稱欄位，透過文字正規化與既有名稱對照資料，將不同寫法的名稱盡可能對應到標準名稱。

專案重點不是建立通用型資料清理平台，而是將特定資料整理流程做成可操作的介面，降低人工逐筆核對名稱的工作量。

## 主要功能

- 透過 Streamlit 提供檔案上傳、欄位選擇、結果預覽與下載介面。
- 讀取 CSV，讓使用者選擇需要比對的名稱欄位。
- 將名稱轉為大寫，移除常見公司組織型態及標點符號，產生正規化字串。
- 使用既有對照資料進行精確比對，將名稱映射至標準名稱欄位（程式中的 `AC`）。
- 對精確比對未成功的資料，使用 Jaro-Winkler 字串相似度進行近似比對；程式設定的門檻為 0.95。
- 將處理結果輸出為 CSV，供後續檢查或使用。

## 處理流程

1. 載入名稱對照資料及其正規化欄位。
2. 使用者上傳 CSV，選擇待處理的名稱欄位。
3. 對輸入名稱進行大小寫、組織型態與符號正規化。
4. 先以正規化名稱查找既有對照資料。
5. 對尚未配對的名稱執行 Jaro-Winkler 相似度比對。
6. 顯示配對結果並提供 CSV 下載。

## 實作範圍與注意事項

- 目前可由 `app.py` 明確確認的完整操作流程以 CSV 上傳、精確比對、未匹配資料的相似度比對及 CSV 下載為主。
- 介面也提供 Excel 上傳選項；目前版本可讀取第二個工作表並顯示資料，但程式中尚未看到後續比對與下載流程完整接上，因此不將 Excel 流程描述為已完成。
- 相似度門檻 0.95 是程式中的設定值，不代表已經透過獨立標註資料驗證其準確率。
- 模糊比對結果的欄位指派方式與進度迴圈仍有可改善之處；詳見 [PROJECT_RETROSPECTIVE.md](PROJECT_RETROSPECTIVE.md)。
- 本文件依照版本庫中的程式與檔案進行靜態整理，沒有宣稱目前環境已重新部署或完成端到端測試。
